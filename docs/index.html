📦 ACI — Agent Interaction Specification

Manifest schema and validation library for declaring agent identity, capabilities, and constraints.

pip install aci-spec
from aci import SpecValidator
v = SpecValidator()
manifest = v.validate_manifest({
    "agent_name": "my-agent",
    "version": "1.0.0",
    "capabilities": ["web", "code"],
    "constraints": {"max_tokens": 16000}
})

🔗 AIP — Agent Interaction Protocol

Receipt chain data types for recording and verifying agent actions with E0-E4 evidence grading.

go get github.com/empirelabs/aip
import "github.com/empirelabs/aip"
receipt := aip.AgentReceipt{
    AgentName:  "my-agent",
    ActionType: "execute",
    Status:     "allowed",
}

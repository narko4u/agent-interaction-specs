Open Standards

The Agent Standards Stack

Three complementary specifications that together form a complete framework for agent interoperability and governance.

ACI

Agent Capability Interface

pip install aci-spec

A discoverability and interoperability standard. Agents declare capabilities, tools, and constraints in a machine-readable format. Enables autonomous agent-to-agent negotiation and audit.

AIP

Agent Interaction Protocol

go get github.com/empirelabs/aip

A transport-agnostic protocol for agent-to-agent and agent-to-system communication. Handles request routing, capability negotiation, and execution receipts with cryptographic verification.

AJSON

Agent JSON Specification

pip install ajson-spec

A superset of JSON optimized for agent manifests and execution contexts. Supports typed schemas, temporal data, cryptographic proofs, and cross-reference resolution out of the box.

These standards are open source (MIT). Inspect the code, contribute, or build your own implementation.

Compliance Enforcement

From Standards to Governance

Standards give you interoperability. An enforcement layer gives you compliance. Here's how the stack connects.

  • 1

    Declare with ACI

    Agents publish capability manifests describing their tools, data access, and operational constraints in a standardised format. Every capability is enumerable and auditable.

  • 2

    Execute with AIP

    All agent actions flow through AIP — requests, responses, tool calls, and data access produce signed cryptographic receipts. Nothing happens off-ledger.

  • 3

    Govern with Enforcement Layer

    A runtime that validates every action against policy before execution, records evidence for audit trails, and enforces compliance boundaries. Humans get real-time oversight dashboards.

  • 4

    Audit with Evidence

    Every action generates an evidence chain: who requested what, which policy was checked, what was approved or denied, and the cryptographic receipt. Ready for regulatory submission.

# ACI manifest — agent declares capabilities

  "agent": "research-agent-v1",
  "capabilities": ["web_search", "code_execution"],
  "constraints": { "max_tokens": 32000 }
